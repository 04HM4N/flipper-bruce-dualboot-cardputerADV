⚠️ Critical: Flash Mode DIO — Do NOT Use QIO!All images are compiled for and must be flashed in DIO mode. Never flash using --flash_mode qio, even if the M5Stack board configuration JSON references QIO:Flashing with QIO causes the 2nd-stage bootloader to hang during flash initialization, leading to a severe WDT reboot loop (rst:0x7 TG0WDT_SYS_RST, every ~1.2s) resulting in a black screen, despite a reported successful flash process.Because of this, sdkconfig.dualboot_* and Bruce's configuration files enforce DIO. The builder flashes using --flash_mode dio, and merged binaries bake DIO settings directly into headers (--flash_mode keep prevents accidental alteration when flashing manually).❓ TroubleshootingSymptomCause / SolutionBlack screen after flashingImage was flashed using QIO mode → Reflash using --flash_mode dio or --flash_mode keep with the merged binary."LittleFS is full" on first Bruce bootOutdated partition table (192 KB spiffs) → Reflash.
